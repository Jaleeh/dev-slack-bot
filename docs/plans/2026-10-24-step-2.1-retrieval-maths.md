# Step 2.1: Retrieval Maths Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two pure functions, recall@k and reciprocal rank, that score one question's ranked retrieval results against its correct files. Plus the ADR that records hand-written evals.

**Architecture:** A new `evals` package beside `app/` in `backend/`. This slice adds only `evals/retrieval_metrics.py`: pure functions, no I/O, no dependencies. The run-level mean (MRR, mean recall@k) is `statistics.fmean` over these per-question scores, called by the runner in 2.3. No wrapper is added here.

**Tech Stack:** Python 3.14, pytest, Ruff, mypy (strict). No new dependencies.

**Spec:** [`docs/specs/2026-10-24-step-2-evals.md`](../specs/2026-10-24-step-2-evals.md), section "2.1 Retrieval maths"

## Global Constraints

- Branch `step-2.1-retrieval-maths`. One PR, code only.
- Pure core: `retrieval_metrics.py` imports nothing from `app/` and does no I/O.
- File paths are compared exactly, relative to the repository root. No normalisation.
- Duplicate paths in the results count once, at their first rank.
- k = 5 and k = 10 are the reported values (used by 2.3). The functions take any `k >= 1`.
- Expected values in tests are hard-coded, never computed in the test.
- **Commit only when the user says so.** The commit steps below are there for when they do.

## Review Focus

1. **Fewer results than k.** For example, 3 results with k = 5. Recall is computed over what's there, with no error. Tested in Task 1.
2. **The same correct file returned twice.** Recall must never go above 1.0, and the duplicate must not push a later file's rank down. Tested in Task 1.
3. **No results at all.** Both functions return 0.0. Tested in Task 1.
4. **A path written differently** (`./src/a.py` vs `src/a.py`). This counts as a miss, which pins the exact-match rule so a retriever returning unclean paths shows up as a low score. Tested in Task 1.
5. **Invalid input** (`k < 1`, or no correct files). The function raises `ValueError` naming the argument, rather than dividing by zero. Tested in Task 1.
