# Step 3.3b: Re-grade a saved agent run Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make regrade RUN=<results file>` judges a saved `make eval-agent` run several times without running the agent, so a docs-off run can be compared with the baseline despite judge noise.

**Architecture:** `eval-agent` results also store each question's evidence (the tool output the judge reads). A new `evals/regrade.py` loads a saved run, replays the tool calls of questions saved without evidence, checks the replay against the recorded `evidence_chars`, then grades every non-empty answer `REPS` times and writes `regrade-<timestamp>.json`.

**Tech Stack:** Python, pydantic, the existing `grade`, `agent_metrics`, `search_tools` and `fetch_sample_repo`.

**Spec:** design agreed in chat on 2026-10-29, summarised below. Parent spec: [`docs/specs/2026-10-27-step-3-direct-retrieval.md`](../specs/2026-10-27-step-3-direct-retrieval.md). Parent plan: [`2026-10-28-step-3.3-agent-evals.md`](2026-10-28-step-3.3-agent-evals.md).

**Why:** the agent repeats its answers exactly (`agent-20261028T135238Z` and `agent-20261029T083527Z` have all 30 answers and the same token total), but the judge doesn't: "all facts stated" went 13 → 9 on the same answers. The old docs-off rule (≥3 more) is smaller than that noise.

## Global Constraints

- `REPS` defaults to 5 and must be a positive whole number.
- Empty answers are never judged (same as `eval-agent`).
- Replayed evidence must have exactly the recorded `evidence_chars`; otherwise stop and name each mismatched question. Never grade on evidence that differs.
- The question set's `version`, `repo` and `ref` must match the run's `setup`; otherwise stop.
- Retrieval numbers come from the source run unchanged.
- Commits only when the maintainer says so.

## Review Focus

1. A results file from before this change (no `evidence` key) loads and replays: Task 2's replay test uses one.
2. The judge dies partway: finished passes stay in the file. Task 2 test.
3. `RUN` missing, not a file, or not an agent run: stops with one line, no model call. Task 3 test.
4. `REPS=0` or `REPS=abc`: stops with one line. Task 3 test.
5. Question set changed since the run (different `ref`): stops before replaying. Task 3 test.

### Task 2: Replay and re-grade core

**Files:**
- Create: `backend/evals/regrade.py`
- Test: `backend/tests/integration/evals/test_regrade.py`

**Interfaces:**
- Consumes: `AgentRun`, `RunSetup` from `agent_runner`; `QuestionScore`, `evidence`, `agent_metrics`, `AgentMetrics` from `agent_scores`; `grade`; `search_tools`; `DirectSearch`, `open_scope`; `ToolCallRecord`, `Outcome.RAN`.
- Produces:
  - `class EvidenceMismatch(ValueError)` with `ids: tuple[str, ...]`; message names each id with recorded vs replayed chars.
  - `class Spread(BaseModel)`: `mean: float`, `low: float`, `high: float`.
  - `class RegradeSetup(BaseModel)`: `started_at`, `git_commit`, `source: str`, `reps: int`, `judge_model: str`.
  - `class GradedPass(BaseModel)`: `checks: dict[str, tuple[CheckResult, ...]]` keyed by question id.
  - `class Regrade(BaseModel)`: `setup: RegradeSetup`, `source_setup: RunSetup`, `questions: tuple[QuestionScore, ...]` (evidence filled), `passes: tuple[GradedPass, ...]`; computed `metrics: tuple[AgentMetrics, ...]` (one per pass, via `agent_metrics` on the questions with that pass's checks) and computed `summary: dict[str, Spread]` for `fact_score`, `all_facts_stated`, `faithfulness_passed`, `inconclusive`.
  - `@dataclass(frozen=True) class RegradePlan`: `setup: RegradeSetup`, `source: AgentRun`, `questions: dict[str, Question]`, `repo: Path`, `path: Path`.
  - `with_evidence(source: AgentRun, repo: Path) -> tuple[QuestionScore, ...]`: saved evidence kept; questions with `evidence == ""` and `evidence_chars > 0` get their `"ran"` calls replayed through `search_tools(DirectSearch(open_scope(repo, source.setup.agent.search_skip)))`, rebuilt as `ToolCallRecord(name, args, str(output), Outcome.RAN)` and joined with `evidence`. Raises `EvidenceMismatch` listing every mismatch at once.
  - `regrade_run(plan: RegradePlan, judge: BaseChatModel) -> Regrade`: calls `with_evidence`, then for each of `setup.reps` passes grades every non-empty question and rewrites the results file after each finished pass.
